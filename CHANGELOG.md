# Changelog

## 1.0.0

Initial release.

- Control a Xiaomi Mi Monitor Light Bar (MJGJD01YL) from Windows over an ESP32 + nRF24L01
- On/off, reset, brightness and color temperature with live visualization
- Auto-connect and reconnect to the ESP32
- Global hotkey and system tray with close-to-tray
- Fetch the remote ID from the original remote
- Configurable serial port, theme, and startup behavior
- Turns the light off while the PC sleeps and back on when it wakes
